# Atlas Capture Alpha

Обновлено: 5 августа 2026 года.

## Назначение

Atlas Capture — автономный мобильный интерфейс для быстрого захвата мыслей, задач и заметок. Работает локально в браузере без сервера и синхронизации.

## Реализованные функции

- Текстовый захват с сохранением в локальный Inbox
- Голосовой ввод через SpeechRecognition API (ru-RU)
- Выбор подсказки типа: Задача, Мысль, Заметка
- Сохранение многострочного текста как одной записи
- Просмотр последних 8 записей
- Полноэкранный список всех входящих
- Удаление записей с Undo
- Честные статусы: «Локальный режим», «Сохранено на этом устройстве»

## Локальное хранение

Данные сохраняются в localStorage браузера по ключу `atlas_v2_data` — тому же, что использует Atlas Studio. После синхронизации записи будут доступны на обоих устройствах.

## Структура Inbox-записи

```json
{
  "id": "inbox-...",
  "text": "Текст записи",
  "rawText": "Текст записи",
  "inputType": "text",
  "source": "mobile-capture",
  "status": "new",
  "userHint": null,
  "deviceId": "device-...",
  "createdAt": 1785700000000,
  "updatedAt": 1785700000000
}
```

Поля:
- `text` — текущий рабочий текст
- `rawText` — исходный текст (не изменяется)
- `inputType` — `text` или `voice`
- `source` — `mobile-capture` или `desktop-capture`
- `status` — `new`, `reviewed`, `processed`, `discarded`
- `userHint` — `task`, `thought`, `note` или `null`
- `deviceId` — стабильный идентификатор устройства

## Как открыть capture.html

1. Запустите локальный HTTP-сервер в папке проекта
2. Откройте `capture.html` в браузере
3. На Android рекомендуется Chrome или Samsung Internet

Для локального сервера:
```bash
npx serve .
# или
python -m http.server 8000
```

## Требования для микрофона

- HTTPS или localhost
- Разрешение на доступ к микрофону
- Поддержка SpeechRecognition API (Chrome, Edge, Safari)

При отсутствии поддержки голосовой ввод отключается, текстовый захват работает полностью.

## Ограничения alpha

- Данные хранятся только в текущем браузере
- Нет обмена между устройствами
- Нет PWA и установки приложения
- Нет фото, вложений, геолокации
- Нет автоматического распределения записей
- Нет Mobile Today
- Нет интеграции с картой жизни

## Что будет следующим

1. **PWA** — установка на домашний экран, работа офлайн
2. **Испытание на Android** — ежедневное использование 1-2 недели
3. **Mobile Today** — ближайшие задачи на мобильном
4. **Синхронизация** — обмен между телефоном и ПК
5. **Умное распределение** — автоматическая классификация записей

# Atlas Capture PWA Alpha.2

Обновлено: 6 августа 2026 года.

## Назначение

Atlas Capture Alpha.2 превращает существующий мобильный интерфейс в устанавливаемое PWA-приложение для Android.

## Реализованные функции

- Установка на главный экран Android
- Работа офлайн
- Получение текста через «Поделиться» из других приложений
- Обновление приложения с сохранением данных
- Информационная панель

## Установка на Android

1. Откройте `capture/` в Chrome на Android
2. Нажмите «Установить приложение» (или меню браузера → «Добавить на главный экран»)
3. Приложение появится на главном экране

## Офлайн-режим

При отсутствии сети:
- Приложение открывается
- Существующие Inbox-записи доступны
- Можно создавать новые записи
- Черновик работает
- Голосовой ввод может быть недоступен

Статус показывает: «Офлайн · записи сохраняются на устройстве»

## Share Target

Из любого Android-приложения можно поделиться текстом или ссылкой в Atlas Capture:

1. Выберите «Поделиться» → «Atlas Capture»
2. Текст появится как черновик
3. Проверьте запись перед сохранением

При существующем черновике предлагается выбор:
- Добавить к черновику
- Заменить черновик

## Обновление приложения

При доступности нового service worker:
- Показывается панель «Доступно обновление»
- Кнопка «Обновить» сохраняет draft и перезагружает
- Данные (Inbox, draft) не удаляются

## Локальное хранение

- `atlas_v2_data` — основная база Atlas (localStorage)
- `atlas_capture_draft_v1` — UI-черновик (localStorage)
- Service Worker cache — только ресурсы Capture

## Известные ограничения

- Синхронизация между устройствами не реализована
- Файлы и изображения не принимаются через «Поделиться»
- Голосовой ввод зависит от браузера и может не работать офлайн

## Очистка при разработке

```javascript
// Удалить service worker
navigator.serviceWorker.getRegistrations().then(regs => regs.forEach(r => r.unregister()));

// Очистить cache
caches.keys().then(names => names.forEach(n => caches.delete(n)));
```

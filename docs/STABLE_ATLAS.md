# Устойчивая карта — 0.13.0-alpha.6

Вторая одобренная итерация плана `superpowers/plans/2026-11-08-map-as-assistant.md`.
Сферы и проекты имеют пространственный адрес `mapSlot`. Он выделяется Core при
создании, не зависит от viewport, Task status/priority, числа задач или фильтра.
Миграция schema 11→12 назначает адреса существующим сущностям, используя прежний
порядок. Снимок перед миграцией сохраняется существующим recovery flow.

`js/core/spatial-address.js` — назначение/нормализация адресов без UI.
`js/features/map/spatial-layout.js` — постоянная сетка сфер, вложенная сетка
проектов, ephemeral страницы. Viewport меняет камеру; CSS/world координаты
пересчитываются через DPR. Добавление проекта может расширить контур своей сферы,
но не перемещает её центр и соседние проекты/сферы. Удаление не уплотняет адреса.
Перенос проекта выделяет адрес назначения; guarded Undo восстанавливает прежний
или отказывает, если его уже занял новый проект. Связи Task/Knowledge/C2 прежние.

На странице сферы до 18 проектов; её независимые задачи имеют отдельное место.
Страницы сохраняют пространственные места, переключаются в навигаторе выбранной
сферы/проекта. Поиск пустого проекта тоже работает и открывает нужную страницу.
Переход к Task раскрывает её проект/страницу даже за пределами первых 12 задач.
На полотне проекта до 12 приоритетных задач, остальные доступны в Inspector;
поиск/линзы и переход к задаче выдвигают нужные записи на полотно. Выполненное
не увеличивает геометрию проекта бесконечно.

Единый режим размещения заменяет зависимость полотна от legacy auto/manual.
Старые pos/_pos и settings не удаляются, но не управляют размещением. Drag
переносит контекст; внутри прежнего контекста интерфейс объясняет автоматическое
место и не сохраняет бессмысленную позицию. Свободное закрепление позиций не
входит в эту итерацию. Камера и страницы остаются session-only.

Обзор показывает сферы и знаки проектов, детали появляются с масштабом. Камера
учитывает нарисованный шестигранник и подписи; общий вид допускает масштаб до
2.5%, slider — от 3%. Первое содержимое пустой карты автоматически попадает
в кадр. Центр проекта нельзя перехватить невидимым hit slop задачи; реальные
попадания в Task имеют приоритет. Reduced motion применяет камеру сразу.

## Реалистичные сценарии и исправления

`tools/smoke-life-scenarios.mjs` проходит через UI в изолированном Chromium:

1. «Не забыть купить молоко и батарейки» → Quick Capture → Processing → новая
   сфера «Дом и быт» → Task без проекта → на сегодня → выполнено → reload.
2. «Отремонтировать крепление на велосипеде» → Processing → новая сфера
   «Мастерская» при уже существующей сфере → новый проект «Ремонт велосипеда» →
   открытие → желаемый результат/следующий шаг → сохранение.
3. Маркировка подшипника → Note → тот же проект → reload с сохранёнными связями.

Исправлены: создание сферы из Processing теперь доступно и при непустом Atlas;
после Task routing есть квитанция с открытием без потери последовательного разбора;
законченный проект не предлагается назначением новой Task (Knowledge разрешён);
ошибки inline создания контекста сообщаются пользователю. Скрытые фильтрами и
страницами объекты раскрываются при целевом переходе/поиске. AI классификации нет.

## Проверка

- `tests/spatial-address.mjs`: геометрия, idempotent migration, Task changes,
  project move/Undo, reload, storage rollback, schema-11 import.
- `tools/smoke-stable-atlas.mjs`: 12 сфер, 60 проектов, 361 Task; неизменность
  координат при добавлении/изменении Task, resize, reload; ещё 18 проектов для
  overflow, поиск пустого проекта на следующей странице и переключение страниц.
- `tools/smoke-project-review.mjs`, `smoke-project-move.mjs`,
  `smoke-visual-atlas.mjs`: прежние пользовательские flows.
- Browser regressions: map-hit-hierarchy/card/lens/access. Иерархия тестирует
  projectId явно: groupId теперь обозначает контейнер и для проектных Tasks.
- Baseline, PWA import graph, визуальная проверка dark/light при 1440×900 и
  1024×768. Артефакты `output/stable-atlas*`, `output/life-scenarios`.

На одном локальном Chromium и одинаковом наборе (10 повторов): предыдущий
7702fd5 — layout ~4.19 ms, draw ~8.81 ms; текущий — layout ~2.6–3.4 ms,
draw ~0.65–0.81 ms. Это диагностические локальные замеры, не обещание FPS на
других устройствах. Семантические уровни убрали ненужные подписи и расчёт их
соседства из общего вида. Результаты сохранены в `output/stable-atlas/performance.json`.

Ограничения: свободного редактирования геометрии нет; задачи внутри контейнера
могут перераскладываться; страницы не сохраняются между запусками. Долговременная
история внимания, ритм сфер и AI (третья итерация) не начаты. Sync v1 не расширен.

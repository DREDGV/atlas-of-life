# Карта → Сегодня — план реализации

Статус — одобрен и реализован в 0.13.0-alpha.8. Основа — `codex/map-attention` на `453c950`.

**Цель** — прямо на карте понять, что требует внимания сегодня, увидеть причину и за одно явное действие взять задачу в план или открыть уже выбранную задачу в «Сегодня».

## Что мешает сейчас

- «Обзор жизни» показывает просрочки, даты обзора и проекты без шага. Срок на сегодня и подтверждённый следующий шаг активного проекта не складываются в короткий список действий на день.
- Фокус, план и их загрузка уже есть в «Сегодня». Карта видит их отдельными признаками, но не показывает их вместе с причинами добавить следующую задачу.
- Действие «На сегодня» появляется после выбора задачи. Прямого перехода к её строке в «Сегодня» нет.
- В текущей модели Today раздел сроков берёт задачи с пустым `plannedDay`. Если срок сегодня, а работа запланирована на завтра, конфликт легко пропустить в списке будущих задач.

## 1. Собрать предложения из существующих данных

Файлы — новый `js/features/map/today-suggestions.js`, регрессия `tests/map-today-suggestions.mjs`. Источники — `dayView`, `dayCapacity`, `dueState`, явный `nextActionId` и состояние проекта. Вход — состояние Atlas и фиксируемое локальное время. Выход — текущий фокус, объём плана и кандидаты с причинами.

- [x] Показать уже выбранный фокус и объём сегодняшнего плана, включая задачи без оценки. Задачи в плане не дублировать в предложениях.
- [x] Ранжировать предложения в понятном порядке. Сначала просроченные задачи и задачи со сроком сегодня, затем незапланированные подтверждённые шаги активных проектов. Среди сроков учитывать дату и указанное время, среди равных кандидатов — явный приоритет пользователя и стабильный порядок.
- [x] Показать первые три предложения и раскрытие остальных. Обязательства видны и у задач без сферы или в проекте на паузе. Подтверждённый шаг на паузе сам по себе не даёт предложения. Завершённые задачи исключены. Просроченный старый план сам по себе не определяет срочность.
- [x] Если срок раньше уже выбранного будущего дня, показать обе даты и предложить явный перенос. План на будущее без такого конфликта остаётся в своём дне.
- [x] Тестом закрепить порядок, локальную полночь, дубли, полное отсутствие кандидатов и случаи из предыдущих пунктов.

## 2. Довести переход до конкретной задачи

Файлы — `index.html`, `styles.css`, `js/view_map.js`, новый DOM-компонент рядом с `js/features/map/attention-view.js`, интеграция в `js/app.js` и `js/view_today.js`. При переходе использовать существующее раскрытие объекта на карте и строку `[data-id]` в Today.

- [x] Поставить блок «Сегодня на карте» в верхней части боковой панели. У каждой строки есть задача, контекст, причина и основное действие. Требования к UI — доступность с клавиатуры, чёткий фокус, читаемость в светлой и тёмной темах при 1024×768 и 1440×900.
- [x] «На сегодня» сохраняет выбранную задачу через `updateTask` и открывает её строку в текущем дне. Если есть будущий план, действие явно называет исходный день. У уже выбранной задачи доступен переход к её строке без записи. Название задачи ведёт к ней на карте.
- [x] В «Сегодня» оставить существующий выбор «В фокус» и завершение. Переход со строки карты открывает текущий день независимо от ранее просматриваемой даты, прокручивает к задаче и ставит клавиатурный фокус.
- [x] Сбой сохранения показать у действия, не переключая экран. Проверка учитывает удалённую или уже завершённую задачу и повторное нажатие. Запись меняет только выбранный план через Core, `due` и существующий фокус сохраняются.

## 3. Приёмка

- [x] В браузере пройти «Купить продукты → срок сегодня → На сегодня → строка Today → Выполнено → запись в обзоре» с проверкой после перезагрузки.
- [x] Пройти «Ремонт велосипеда → рекомендованный следующий шаг → план дня», сравнить с таким же проектом на осознанной паузе. Просроченная задача проекта на паузе остаётся видна.
- [x] Пройти «Срок сегодня, план завтра → показать конфликт → перенести только явно», сверить неизменность срока и обычное открытие «Сегодня». Проверить заполненный фокус, пустой Atlas, ошибку хранилища и повтор.
- [x] Проверить имеющиеся Today, Review и Sync регрессии плюс baseline. Отдельно проверить коммит без существующих рабочих правок Today. По результату приёмки обновить roadmap и ledger.

## Границы этапа

Версия — `0.13.0-alpha.8`. Рекомендации вычисляются при чтении. Для них достаточно текущей схемы, а все пользовательские решения фиксирует существующий Core. История обзора служит подтверждением результата. Этап ограничен переходом от карты к текущему дню.
